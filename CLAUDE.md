# Kona

Kona is a personal desktop workspace for Claude Code. It is for one person (the owner), on one Windows PC. The plan is in `kona-space-app.md`. Read it first.

## This is NOT a Miralis repo

Ignore the Miralis parts of the global instructions here:
- the `miralis` skill and every `miralis-*` skill
- the canon sync (the tools in `C:\miralis-canon`)
- `miralis.css`, `miralis.js`, `mi-*` classes, Stage and Sheet modes, `miralis.repo.json`
- the Miralis effort rule
- the shared Miralis server

Do not ask whether this is a Miralis product. The answer is no. `C:\miralis-canon` may be read for ideas. Never run its tools for Kona.

## How to talk to the owner

- Plain words. Assume little tech knowledge. Explain a term the first time, with a short example.
- Short and direct. Facts first.
- Say what you did, what you did not do, and what you could not check.

## Rules

- Ask before downloading, installing, deleting or killing anything, and before any command on a server.
- The PC is small (7.3 GB RAM, 4 cores). Say what a heavy step will cost before doing it.
- Never write keys, tokens, passwords, IP addresses or e-mail addresses into this folder or into notes.
- Do not start a Claude session with `D:\kona-refs` as the working folder. Those cloned repos carry their own `CLAUDE.md` files. They are reading material only.
- Tags in `kona-space-app.md`: (seen) checked on this PC, (web) read on a web page, (proposal) a suggestion, (to verify) test it before relying on it.
- When a decision changes, update the Decisions table in `kona-space-app.md`.
- The owner's UI taste is written down in `C:\miralis-canon\DESIGN.md` (Named Rules, Do's and Don'ts). Read it before designing or judging any Kona screen. Take the discipline (no kicker labels, one accent per area, state as glyph plus word, flat at rest, plain words), never the marks (no hexagon, cut lines, ticks). Kona's own look stays dark, roomy, calm, technical and warm. Section 10.6 of the note has the list.
- Working in FigCraft (the design tool): read `docs/FIGCRAFT.md` first. It lists what Claude can do, what it must do and the traps found. The design is rebuilt by script from `docs/design/build/`.
