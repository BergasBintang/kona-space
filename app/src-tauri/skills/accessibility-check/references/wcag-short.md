# The short list (based on WCAG 2.2 level AA)

**Can they see it**
- Text alternatives for pictures that carry meaning; empty ones for decoration.
- Contrast 4.5 to 1 for text, 3 to 1 for large text, icons and field borders.
- Works at 200 percent zoom and in a narrow window without scrolling sideways.
- Colour is never the only signal.

**Can they use it**
- Everything works from the keyboard, with no traps.
- Focus is visible and is not hidden behind sticky bars.
- Targets at least 24 by 24 pixels.
- Anything done by dragging also has another way.
- Time limits can be extended.
- Motion can be stopped; no flashing.

**Can they understand it**
- The language of the page is set.
- Things do not change just from focus or typing.
- Errors are named and suggest a fix.
- The same thing is in the same place, with the same name.

**Does it work with their tools**
- Real elements first (button, a, label, h1). Roles and aria only when no real element fits.
- Name, role and state can be read by a screen reader.
- Status messages are announced without moving the focus.
- A dialog takes the focus, keeps it inside, and gives it back when closed.
