# Page SEO check

Look at the page itself, as served, not only at the source code. Report only; change things when asked.

1. **Can it be found at all?** Open `references/checks.md` and go down it, starting with crawling and indexing. A blocked page cannot rank, however good it is, so check this first.
2. **Does the page say what it is about?** Title, description, one main heading, words that match what people search for.
3. **Does the content answer the question?** Honest answer. Thin or copied pages are the most common real problem.
4. **Is it fast and readable on a phone?**
5. **Does the rest of the site lead to it?** Links from other pages, and sensible addresses.

**Rank by what stands in the way most:**
- Blocked from search: fix today.
- Wrong or missing title, thin content, duplicates: fix next.
- Small details: only if there is time.

For each finding: what is wrong, on which page, how you know, what to change. Say what you could not check. Rankings and traffic need the owner's own data (for example Search Console), so never invent them or promise any result.
