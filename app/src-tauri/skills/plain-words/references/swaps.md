# Common swaps

| Instead of | Write |
|---|---|
| utilize, leverage | use |
| initiate, commence | start |
| terminate | end, stop |
| in order to | to |
| due to the fact that | because |
| at this point in time | now |
| prior to | before |
| subsequently | then, after |
| a number of | some, or the number |
| ensure | make sure |
| facilitate | help |
| functionality | feature, what it does |
| implement | build, add |
| remediate | fix |
| resolve the issue | fix it |
| was performed | [say who] did |
| it should be noted that | (delete) |
| seamless, robust, powerful | (delete, or give the fact) |

**Sentences that say nothing**
- "Great question!"
- "I hope this helps."
- "Let me know if you have any questions."
- "Here is a summary of what I did" (just give it).

**Terms that often need explaining**
Commit, branch, deploy, migration, cache, token, API, server, build, environment. Explain once, briefly, then use the word.
