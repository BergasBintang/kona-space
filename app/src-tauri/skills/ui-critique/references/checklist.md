# What to look at

**Order**
- One clear main action on each screen.
- Size, weight and colour agree on what matters most.
- Nothing competes with the main thing for no reason.

**Space**
- Related things sit closer together than unrelated things.
- Spacing comes from one scale, and the edges line up.
- Boxes inside boxes only when they mean something.

**Text**
- Body text is large enough to read and lines are not too long.
- Few sizes and weights; each has one job.
- Words are plain and the same thing has the same name everywhere.

**Colour**
- Colour carries meaning, and there is no more of it than needed.
- State is never shown by colour alone: add a word or a glyph.
- Text is readable on its background, including when disabled or on hover.

**Behaviour**
- Everything clickable looks clickable and answers when pressed.
- Busy, failed, empty and first-time states exist.
- Nothing loses work without warning.

**Fit**
- It looks like the rest of the product.
- It holds up when narrow, when wide, and with very long text.
- It can be used with the keyboard alone.

**Filler to remove**
- Tiles with numbers that nobody acts on.
- Decoration that says nothing, labels above labels, three cards where one sentence would do.
