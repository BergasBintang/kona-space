## Then check the rules

- [ ] Reduced motion changes the screen, it does not only switch things off.
- [ ] Every hover and drag has a keyboard version.
- [ ] Every change of state is also said in words, for screen readers.
- [ ] Nothing loops without meaning, and loops pause when hidden or off screen.
- [ ] Nothing heavy: no full-window shader, no library added without a reason.
- [ ] Looked at moving in a real browser, with the keyboard only, in a narrow window.
