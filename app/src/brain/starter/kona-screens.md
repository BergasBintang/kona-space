# What each Kona screen is for

- **Sessions:** chat with Claude, approve or refuse each step, see what a session costs.
- **Board:** your tickets in five columns; start a session from a card. See [[kona-board]].
- **Worktrees:** every working copy of the repo, merge and remove. See [[tickets-and-worktrees]].
- **Files:** read-only view of the project's files.
- **Leftovers:** programs sessions started and left running; scratch files. See [[kona-leftovers]].
- **Costs:** what sessions cost by project, role, ticket, account, model, day. See [[kona-costs-and-plan-bars]].
- **Mockups:** a big screen in the Lounge. The pages people drew for the project, clicked through in drawn devices of five sizes. See [[kona-mockups]].
- **Connections:** the servers and the GitHub repos a project may reach, and which roles may use each. A role that is refused a server asks the owner to add it here.
- **Roles:** the ten starting roles and your own. See [[roles-and-permission-modes]].
- **Voice:** how Claude and Kona talk to you.
- **Accounts:** the Claude logins Kona can use. They live in Settings on the welcome page (press the Kona button at the top left); each project uses one, chosen there or in the project's own Settings.
- **Brain:** this place. See [[how-the-brain-works]].
